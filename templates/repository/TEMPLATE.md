# New layer/feature checklist

- [ ] Ownership and forbidden dependencies are explicit
- [ ] Root and subtree `AGENTS.md` rules are compatible
- [ ] Public capability is represented by a focused interface
- [ ] DI registration is in the owning composition root
- [ ] Package versions are central
- [ ] Assembly metadata is in the project file
- [ ] Configuration has a themed directory, README, typed options, and startup validation
- [ ] Persistent data uses EF Core; exceptional SQL is centralized and tested
- [ ] Unit and architecture tests cover the boundary
- [ ] `docs/README.md` links the new documentation
- [ ] Templates are updated if the feature establishes a new repository convention
