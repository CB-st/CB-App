# UI templates

Use these files for new MAUI screens. They deliberately reference the shared design system so new work begins with the correct hierarchy and accessibility seams.

| File | Purpose |
| --- | --- |
| `Page.xaml.template` | Token-based page structure with loading, empty, and content regions |
| `ViewModel.cs.template` | Constructor-injected ViewModel boundary |
| `TEMPLATE.md` | Copy procedure and definition of done |

Replace all `__TOKEN__` placeholders. Do not rename existing design-system resources inside the copied page.
